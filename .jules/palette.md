## 2024-06-23 - Accessibility Foundations in HEROS
**Learning:** In minimal, code-heavy UI interfaces like this, global focus states (`:focus-visible`) are easily missed but critical for keyboard navigation, and custom muted text colors often fail WCAG contrast guidelines without tweaking.
**Action:** Always check the root CSS variables for contrast compliance on muted text, and ensure interactive elements (like application logos) are semantic anchor tags.
