## 2024-10-24 - Interactive Elements Accessibility
**Learning:** Static landing pages often miss standard focus-visible rings and interactive logo routing to the root directory, hindering keyboard navigation. Moreover, default muted text (#666 on #0a0a0a) fails WCAG contrast requirements.
**Action:** Enforce `:focus-visible` on all anchor and button elements, wrap branding logos in root-level links, and test text colors against WCAG thresholds.
