## 2025-02-23 - Focus Visible Consistency
**Learning:** Pure static HTML pages with manual CSS resets often entirely strip default browser focus rings. The lack of `:focus-visible` styles makes the site completely unnavigable for keyboard users, as there's no visual indicator of what element is currently active. Furthermore, non-interactive visual logos (like a site name) should be wrapped in anchor tags pointing to the root route to adhere to expected web navigation conventions and provide a baseline structural outline for screen readers. Contrast checking revealed that standard gray `#666` fails WCAG AA against deep black `#0a0a0a` (ratio ~3.4), requiring a lighter `#a3a3a3` (ratio ~7.8).
**Action:** When working on standalone HTML files without component frameworks, always explicitly define a global `:focus-visible` rule (e.g., `a:focus-visible, button:focus-visible, .btn:focus-visible`) and verify that brand text functions as a home link. Always verify contrast ratios for muted text on very dark backgrounds using a contrast checker script.
