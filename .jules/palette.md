## 2024-06-04 - Focus Styles for Static Sites
**Learning:** Purely static single-file HTML apps (like the HEROS landing page) can lack basic accessibility defaults since they don't use modern component libraries. Focus rings for keyboard navigation are often missing entirely.
**Action:** Always check `a` and `button` / `.btn` tags for `:focus-visible` styles in custom static landing pages to ensure keyboard users can navigate.
