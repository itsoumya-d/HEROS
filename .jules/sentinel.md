## 2024-06-16 - Prevent Write-Redirect Attacks and FIFO DoS in Bash Scripts
**Vulnerability:** Bash scripts operating on security-critical data files (like `.heros-keys` or `.heros-audit`) are vulnerable to write-redirect attacks if an attacker replaces a file with a symlink. Furthermore, tools like `awk` can block indefinitely if fed a FIFO or special file, causing a Denial of Service (DoS) for the bridge process.
**Learning:** Utilities in Bash (like `cat`, `awk`, output redirection `>`) will blindly follow symlinks. When dealing with sensitive paths managed by the script, failure to verify that the file is a regular file allows attackers to arbitrarily truncate or overwrite files, or block the process via FIFOs.
**Prevention:** Always implement a fail-closed symlink check (`if [[ -L <file> ]]`) for critical files at startup. Before reading a file with external utilities, enforce a regular file check (`if [[ ! -f <file> ]]`) to reject FIFOs, directories, or missing files.
