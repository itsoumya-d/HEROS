## 2025-02-18 - Batch jq JSON parsing in Bash scripts
**Learning:** In Bash scripts, executing `jq` repeatedly (e.g. 7 separate calls for validation, field extraction, type checking) creates substantial subprocess spawning overhead, especially under load (such as in an MCP server's main event loop handling many JSON-RPC requests per second).
**Action:** Always combine related validation and field extraction steps into a single `jq` invocation. Output the values as an array piped through the `@sh` filter, and then deserialize them directly into a Bash array using `eval "arr=($parsed)"`. To safely handle missing or differently typed JSON without causing `jq` itself to fail with exit code 4 (thus aborting the script), use `try (...) catch ...` wrappers inside the `jq` expression.
