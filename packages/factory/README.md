# @soumyadebnath1619/factory

Software-factory flow diagnostics for Mesmer-shaped engineering orgs. It reads issue/PR/review/deploy events, computes flow metrics, ranks the largest bottleneck and simulates the cycle-time impact of a fix.

## Metrics

Cycle time, PR wait, review duration, deploy frequency, issue response, merged PRs, deploys and active engineers.

```bash
node --experimental-strip-types --test test/*.test.ts
```
