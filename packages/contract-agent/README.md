# @soumyadebnath1619/contract-agent

Juro-shaped contract review tools for an agentic legal workspace. It extracts clauses and facts, scores contract risk, retrieves cited clauses and produces an approval/negotiation plan.

## Tools

`extractClauses`, `extractFacts`, `scoreRisks`, `reviewContract`, `retrieveClauses`, `actionPlan`.

## Run

```bash
node --experimental-strip-types --test test/*.test.ts
```
