# @soumyadebnath1619/fleet

Agentic-founder fleet control plane for Feltsense-shaped companies. It turns market signals into scored opportunities, applies a unit-economics gate, allocates a constrained build budget and emits audit receipts.

## Formula

`score = 0.30*demand + 0.25*WTP + 0.20*speed + 0.15*margin + 0.10*fit - 0.20*competition`

Launch gate: paid preorders > 0, verified revenue > 0, human verification complete, contribution margin > 0, CAC payback <= 6 months, LTV/CAC >= 3x, score >= 0.35.
